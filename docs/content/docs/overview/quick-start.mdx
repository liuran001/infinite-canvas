# 快速开始

如果你只是想先把项目跑起来，优先部署或启动 `web/` 前端。

## Docker 部署（推荐）

项目由前端与自带的服务端组成，两者需要一起部署，用 Docker 最省事：

```bash
git clone git@github.com:liuran001/infinite-canvas.git
cd infinite-canvas
docker compose up -d
```

首次部署请先改掉 `docker-compose.yml` 里的 `ADMIN_PASSWORD` 与 `JWT_SECRET`，详见[部署与使用](/docs/overview/server-mode)。

如果只把 `web/` 部署到 Vercel 这类静态托管，需要另外部署服务端，并让前端能访问到它的 `/api`。

## 本地启动

```bash
git clone git@github.com:liuran001/infinite-canvas.git
cd infinite-canvas
cd web
bun install
bun run dev
```

启动后访问：

```text
http://localhost:3000
```

## Docker 启动

如果你需要基于当前源码构建镜像：

```bash
docker build -t infinite-canvas .
docker run --rm -p 3000:3000 infinite-canvas
```

## 首次使用建议

- 用管理员账号登录 `/admin`，在系统设置里添加模型渠道并为每个模型指定能力，用户才能选到模型。
- 普通用户注册登录后即可使用，画布、素材与生成记录会自动在多设备之间同步。
- 需要免密登录可以在账号设置里添加 Passkey（要求 HTTPS 环境）。

## 说明

- 画布项目、“我的素材”、图片与节点插件都保存在服务端，本地只作缓存。
- 模型渠道与密钥只存在服务端，由管理员在管理后台配置，前端不持有密钥。
