# 部署与使用

无限画布由前端和自带的服务端组成。画布、素材、图片、节点插件与生成记录都保存在服务端，登录同一账号即可在多台设备之间同步。模型渠道与密钥只由管理员在服务端配置，前端不持有任何密钥。

## Docker 部署

镜像内已经包含前端与后端：nginx 托管前端并把 `/api` 反代到容器内的 Node 服务，数据库文件与上传文件都落在 `/app/data`。

```bash
git clone git@github.com:liuran001/infinite-canvas.git
cd infinite-canvas
docker compose up -d
```

访问 `http://服务器IP:3000`。

### 部署前必须改的三个变量

把 `docker-compose.yml` 里的 `environment` 取消注释：

```yaml
    environment:
      ADMIN_PASSWORD: 换成你自己的强密码
      JWT_SECRET: 换成一段随机字符串
      PUBLIC_BASE_URL: https://你的域名
```

- `ADMIN_PASSWORD` — 默认是 `infinite-canvas`，首次启动会用它创建管理员，**务必修改**。
- `JWT_SECRET` — 不设置则每次重启都随机生成，所有人的登录态会失效。可以用 `openssl rand -base64 32` 生成。
- `PUBLIC_BASE_URL` — 服务对外可访问的地址。火山方舟这类上游需要回源读取参考素材，不配置时会退回用 base64 提交，较大的参考视频可能失败。

完整变量清单见仓库根目录的 `.env.example`，包含 MySQL / PostgreSQL 与 S3 兼容对象存储的配置。

## 首次使用的顺序

这个顺序不能颠倒，否则会以为功能坏了：

1. 打开 `http://你的地址:3000/login`，用 `admin` 和你设置的密码登录。
2. 进入 `/admin` → **系统设置** → 新增模型渠道，填入接口地址与密钥，拉取模型列表并为每个模型指定能力（生图 / 文本 / 视频 / 音频）。
3. 回到应用，画布与生图工作台就能选到模型了。

**没做第 2 步的话，模型选择器会提示「服务端未配置模型，请联系管理员」**，因为模型来自管理员配置，不再读浏览器本地。

## 管理后台

用管理员账号登录后访问 `/admin`：

- **用户管理**：新建、编辑、禁用、删除用户，调整算力点与云空间配额。
- **算力点流水**：查看扣除、返还与人工调整记录。
- **系统设置**：模型渠道（可拉取模型列表并做连通性测试）、模型展示名、算力点成本与画质档位加价、各能力默认模型、系统提示词、功能入口开关、注册开关、Linux.do 登录、提示词定时同步。
- **提示词 / 素材**：维护服务端提示词库与公共素材。
- **生成记录**：跨用户审查生成任务的提示词、参数、产出与失败原因。
- **用户内容**：按用户查看其画布结构与已生成的图片。

渠道密钥与 Linux.do ClientSecret 在读取时会被抹成空串，保存时留空表示保持不变。

## 模型配置说明

### 展示名

模型可以配置展示名。例如实际模型名是 `gemini-3.1-flash-image`，填上展示名 `Nano Banana 2` 后，用户在前端看到的就是后者，而请求仍然使用真实模型名。留空则直接显示模型名。

### 画质档位加价

算力点成本除了基础价，还可以按画质档位叠加。例如基础价 1 点，给 `high` 档配 5 点，用户选 4K 生成一张就消耗 6 点。这样不依赖上游是否把分辨率拆成独立模型，任何模型都能按画质定价。

### 关于把分辨率拆成多个模型的反代

有些反代会把同一个模型按分辨率拆成 `xxx`、`xxx-2k`、`xxx-4k` 三个名字。以 codex2api 为例，它的 `-2k` / `-4k` 只是别名，作用是在**请求没有携带 size 时**给一个对应分辨率的默认值；一旦请求带了 size 就以请求为准。本项目前端总会算出精确的像素尺寸再提交，所以**只需要配置基础模型**，画质由画布里的设置决定。

## 功能入口开关

管理员可以在系统设置里控制生图、文本、视频、音频四类功能入口。关闭后所有用户都看不到对应入口——顶部导航、画布工具栏、生成配置节点的模式切换、偏好设置里的相关项都会隐藏。没有配置对应能力的模型时也会自动隐藏。

已有的视频节点与素材不受影响，仍然可以正常查看和播放。

## 云空间

每个账号默认 100MB，所有存在服务端的文件都计入，包括上传的图和生成的图。删除画布或素材时，其引用且没有被其它内容引用的文件会被回收并释放空间。管理员可以在用户管理里为单个用户调整配额。

## 登录方式

- **账号密码**：注册开关由管理员控制。
- **Linux.do 授权**：需要管理员在系统设置里填入 ClientID 与 ClientSecret。已登录的账号可以在账号设置里绑定或解绑。
- **Passkey**：用指纹、面容或设备密码免密登录。**浏览器要求页面处于 HTTPS 环境**（localhost 除外），纯 HTTP 域名下无法使用。

解绑第三方登录或删除最后一个 Passkey 时，如果账号没有设置密码会被拒绝，避免把自己锁在门外。
