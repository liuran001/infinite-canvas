# 服务器模式

无限画布支持两种运行模式，默认是本地模式，服务器模式需要自行部署后端后手动开启。

## 两种模式的区别

| | 本地模式（默认） | 服务器模式 |
| --- | --- | --- |
| 画布与素材 | 保存在浏览器本地，可选 WebDAV 同步 | 保存在服务器，多设备自动同步 |
| 图片与视频 | 保存在浏览器本地 | 保存在服务器，通过直链读取 |
| AI 渠道密钥 | 存在浏览器本地，由浏览器直连接口 | 只存在服务器，前端拿不到明文 |
| 生成过程 | 浏览器直接调用上游接口 | 服务器执行任务，前端只提交与查询 |
| 断网或换设备 | 生成中断即失败，需要重新生成 | 任务在服务器继续跑，重新进入即可恢复 |
| 模型调用脚本 | 支持 | 不支持，需切回本地模式 |

服务器模式最主要的价值是**生成任务不再依赖客户端网络**：提交任务时前端会附带一个幂等键，即使断网重试或刷新页面重新提交，服务端也只会执行一次，既不会重复生成也不会重复扣算力点。

## 部署后端

后端在仓库的 `server/` 目录，与前端一起打包进官方镜像，用 Docker 部署时无需额外操作：

```bash
docker compose up -d
```

容器内 nginx 托管前端并把 `/api` 反代到后端，数据库文件与上传文件都落在 `/app/data`，通过挂卷持久化。

完整的环境变量清单见仓库根目录的 `.env.example`，其中几个必须关注：

- `ADMIN_USERNAME` / `ADMIN_PASSWORD`：首次启动会用它创建管理员，部署前务必改掉默认值。
- `JWT_SECRET`：登录态签名密钥，不设置则每次重启都会重新随机生成，已签发的登录态会失效。
- `STORAGE_DRIVER` / `DATABASE_DSN`：数据库驱动与连接串，支持 `sqlite`、`mysql`、`postgres`，库不存在时会自动创建。
- `PUBLIC_BASE_URL`：服务对外可访问的地址。火山方舟等上游需要回源读取参考素材，不配置时会退回用 base64 提交，较大的参考视频可能失败。
- `FILE_DRIVER`：`local` 落本地磁盘，`s3` 走 S3 兼容对象存储（需要同时配置 `S3_*` 变量）。

## 开启服务器模式

1. 在前端打开「配置与用户偏好 - 服务器」，打开服务器模式开关。
2. 填写服务器地址；如果前后端是同一个域名（例如用官方镜像一体化部署），留空即可。
3. 点击「测试连接」确认能连上。
4. 点击「登录 / 注册」进入登录页，注册或登录账号。

登录后顶部工具栏会显示云状态图标，画布、素材与生成都会自动切到服务器。随时可以关掉开关回到本地模式，本地数据不受影响。

## 管理后台

用管理员账号登录后，可以从「配置与用户偏好 - 服务器」进入 `/admin`：

- **用户管理**：新建、编辑、禁用、删除用户，调整算力点。
- **算力点流水**：查看扣除、返还与人工调整记录。
- **系统设置**：配置模型渠道（可拉取模型列表并做连通性测试）、各模型的算力点消耗、各能力的默认模型、系统提示词、是否开放注册、Linux.do 登录、提示词定时同步。
- **提示词**：维护服务端提示词库与分类，支持从提示词仓库立即同步。
- **素材**：维护全站公共素材。

渠道 API Key 与 Linux.do ClientSecret 在读取时会被抹成空串，保存时留空表示保持不变，不会被覆盖成空。
